Cisco Meraki WLAN Snapshot

Take a WLAN snapshot of a Meraki wireless network. Each snapshot saves a report you can open later and compare with any other snapshot.

Read-only. No changes are made to your Meraki environment. This tool only sends GET requests to the Meraki Dashboard API. It never sends POST, PUT, PATCH or DELETE requests, so it can’t change any setting, device or network. A read-only admin API key is all it needs.

1API key

The key stays in this browser and is sent only to this app on your computer, which passes it to api.meraki.com.

2Network

14 days is the most Meraki keeps for per-radio detail. Use the same period each time so snapshots compare fairly.

3Generate report

What this app reads from Meraki

Every figure in a report comes from these Meraki Dashboard API calls. All are GET requests: the app only reads and never changes anything in your Dashboard. A read-only admin API key is enough.
